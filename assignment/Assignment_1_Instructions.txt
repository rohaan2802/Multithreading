A Revision of Multithreading (Pthreads) & Performance

Before diving deep into the complexities of parallel and distributed systems, it’s crucial to understand why this field is important and how it can be applied effectively. Keeping in view that you already know multi-threading, your first assignment will be an introductory exercise using multi-threading that demonstrates the power of parallelism and the benefits of multi-threading in computational tasks.
You are assigned three problems, a little different in nature/characteristics, and you are required to implement and evaluate all three problems using three approaches (we will call them versions):
V1: Serial Baseline Begin by implementing the task in a single-threaded manner, where the operations are executed in a straightforward, step-by-step sequence. This serves as the baseline for understanding the complexity of the task.
V2: Multi-threaded Execution (default OS scheduling) Next, parallelize the task by utilizing multiple threads. In this version, the operating system will schedule threads across CPU cores (no manual affinity setting).
V3: Multi-threaded Execution (User-Assigned Affinity and Scheduling) Finally, implement the task again using multiple threads, but this time manually assign each thread to a specific CPU core using pthread setaffinity np() and implement a clear scheduling strategy beyond V2.
You will perform performance evaluation (runtime, speedup, efficiency) across multiple thread counts and dataset sizes for each of the variations and reason about the performance gain/loss and submit a report.
